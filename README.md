# Xntrova Technologies – Homepage Redesign Assessment

This repository contains the practical website redesign and development assessment for **Xntrova Technologies**.

---

## 🚀 Live Demo & Getting Started

### Prerequisites
- Node.js (v18+)
- npm, pnpm, or yarn

### Installation
```bash
npm install
```

### Run Locally (Development)
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
npm run build
npm run start
```

## 🛠️ Technical Stack
- **Framework**: Next.js 16 (App Router with Turbopack)
- **Library**: React 19
- **Styling**: Modular CSS (`page.module.css` and `globals.css`) for zero-runtime CSS overhead, clean isolation, and high performance.
- **Typography**: System font stack optimized for rapid load times and cross-platform clarity.
- **Assets**: High-resolution 3x lanczos-filtered image assets and vector SVGs.
